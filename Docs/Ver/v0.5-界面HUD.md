# 0.5 标题、HUD、设置、Log

- 目标：主界面八按钮骨架 + HUD 五键 + 设置四项 + 只读 Log。
- 前置：0.4
- 标签：`v0.5.0`（三段都勾完再打）
- 必读：[游戏设计-界面与操作](../Dev/设计/游戏设计-界面与操作.md)、[接口设计-播放与UI](../Dev/设计/接口设计-播放与UI.md) §6–8
- 做法：一次只做下面一段；该段勾完并测过，再开下一段。不要把三段揉进一次改动。

视觉统一：白底黑字，无程序美术。布局按 1280×720 给能点的骨架即可，不追求像素稿。

## 第 1 段：标题 + 名单

- [ ] `boot` 进入 `title_loop`，显示 `scr_title`（不再停白屏 `pause`）
- [ ] `scr_title`：游戏名「四月，未命名的树」；八按钮都在
- [ ] 无槽：「新的游戏」强调，「继续游戏」可见不可点
- [ ] 有槽：「继续游戏」强调，「新的游戏」仍可点，立刻覆盖、无确认
- [ ] 「后日谈」「里·后日谈」始终显示；未解锁不可点（解锁仍 0.9）
- [ ] 「退出游戏」无确认；标题 `Esc` 不退出
- [ ] 「新的游戏」「继续游戏」走已有 `PlaySession.start_new_game` / `continue_game`
- [ ] `scr_staff_menu`：`COPY_STAFF_LINES`，点击任意处回标题
- [ ] 「鉴赏」「设置」可点进白底占位，点一下回标题（真鉴赏 0.7；真设置第 3 段换掉）

本段不做：HUD、快捷键、设置四项、Log。

测：清槽后应像 TC02。点「新的游戏」进现有 `ch1_start` 占位（还没有 HUD）。名单、退出、标题 Esc。有槽时看「继续」是否强调且可点。

## 第 2 段：HUD + 快捷键

- [ ] 游玩 / 回放显示 `scr_hud`：Return / Auto / Setting / Log / Save；标题不显示
- [ ] Return / `Esc`：走 `commit_leave`（play 写槽回标题；replay 不写）
- [ ] Save / `S`：play 走 `write_line`；replay 按钮不可点、快捷键忽略
- [ ] Auto / `A`：都调用 `toggle_afm`（可用选中态反映 `afm_enable`）
- [ ] Setting / `F1`：先打开第 1 段的设置占位；第 3 段换成 `scr_settings`
- [ ] Log / `L`：本段可先打开白底占位；第 3 段换成 `scr_log`
- [ ] 只绑本表快捷键；不要恢复默认游戏菜单 / 存档柜 / Skip / Hide
- [ ] HUD 避开现有对话框（`say` 底栏 `ysize 180`），挡字再挪

本段不做：设置四项真正生效、只读 Log 列表。

测：TC21 的 Return / Auto / Save（按钮与键一致）。TC06 Return。TC08 仍无回滚 / Skip / Hide / 确认。标题 Esc 仍不退出。Setting / Log 本段只需能打开占位。

## 第 3 段：设置 + Log + 收口

- [ ] `scr_settings` 换掉设置占位：选项四项 + 快捷键只读页（`COPY_HOTKEY_HELP`）
- [ ] 四项：自动播放速度、字号、字体、窗口/全屏；走 `SettingsStore`；改完立刻生效且能持久
- [ ] Android 隐藏窗口/全屏行；Win 可测窗口↔全屏
- [ ] Auto **不**出现在设置项；无音量
- [ ] 设置打开时：`F1` 或关闭按钮关掉设置，不触发 Return
- [ ] `scr_log` 换掉 Log 占位：只读已显示对白；不可点行跳转
- [ ] 选项写入 Log 的系统行留 0.6
- [ ] `config.version` → `0.5.0`；Launcher `renpy lint`

本段不做：鉴赏列表、选择肢、Android 真机返回键（TC23 留 1.0）。

测：TC17；TC21 的 Setting / Log 改为真界面；字号/字体/速度改完重开仍在。Log 里能看到占位对白。
