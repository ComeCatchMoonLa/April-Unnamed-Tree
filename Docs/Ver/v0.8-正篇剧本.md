# 0.8 正篇剧本（ch1–ch3）

- 目标：首章、中章、尾章按剧本可通读；节点自动存档；四 CG 出现即解锁。
- 前置：0.7
- 标签：`v0.8.0`（三段都勾完再打）
- 必读：[Docs/Res/剧本.txt](../Res/剧本.txt)（只读，禁止改）、[游戏设计-产品与叙事](../Dev/设计/游戏设计-产品与叙事.md) §3.1、[接口实现约定](../Dev/实现/接口实现约定.md) §1.4、[游戏设计-存档与播放](../Dev/设计/游戏设计-存档与播放.md) §3
- 做法：一次只做下面一段；该段勾完并测过，再开下一段。不要把三章揉进一次改动。

共用约束（每段都遵守，不必每条再抄）：

- 每句稳定 `line_id`：`{node_id}:{四位}`；只追加不重排。`jump_to_line` 必须能落到**本段已写**的任意句。
- 到达产品表 3.1 节点调用 `on_node_reached`；CG 出现调用 `on_cg_shown`。
- `【BGM】` / `【SE】` 只留标记，不播放。场景 / CG 全指向 `white`，无程序花瓣、光尘、粉像素。
- 单文件 ≤500 行，超了按节点拆；`game/script/`（或章子目录）≤15 个文件。
- 回放从点入节点播到**本章连续已解锁的末句**，不串章、不写槽、不解锁。下一节点未解锁或已是章末则回鉴赏。play 章末才跳下一章，不回菜单。
- 不要改节点 ID，不要写 after / inner 正文（占位 label 留 0.9）。
