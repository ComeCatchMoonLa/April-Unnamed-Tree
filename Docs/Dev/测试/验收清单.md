# 验收清单

- 目的：可勾选用例。全部通过才算出包。
- 读者：测试执行、实现自检、评审。
- 关系：策略见 [测试策略](测试策略.md)。设计来源见各「设计」列。
- 版本：v1.5
- 日期：2026-09-20

记录方式：Pass / Fail / NA。Fail 必须写复现。

平台缩写：W = Windows，A = Android。

## TC01 双端可运行

- 设计：需求分析 §3；原验收 1
- 平台：W A
- 步骤：脱离编辑器启动；确认无网页构建物
- 期望：能进标题；无 Web 包

## TC02 无存档标题

- 设计：界面与操作 §1
- 平台：W
- 步骤：清槽后开游戏
- 期望：只有「新的游戏」，没有「继续游戏」「后日谈」「里·后日谈」

## TC03 有槽不能新开

- 设计：界面与操作 §1；存档与播放 §1.3
- 平台：W
- 步骤：有槽且尚未解锁后日谈时看标题
- 期望：主进度键是「继续游戏」，没有「新的游戏」也没有「后日谈」「里·后日谈」；点继续从槽内 `line_id` 句首播

## TC04 继续游戏句首

- 设计：存档与播放 §1
- 平台：W
- 步骤：打到一半点 Save，回标题继续；另测杀进程再开
- 期望：从该 `line_id` **开头**播放，不恢复半句打字

## TC05 节点自动存档

- 设计：产品与叙事 §3
- 平台：W
- 步骤：到达任一关键节点后立刻杀进程再开，点继续
- 期望：从该节点句首继续

## TC06 Return / 退出写槽

- 设计：界面与操作 §4；存档与播放 §1.3
- 平台：W
- 步骤：游玩中 Return；另测关窗
- 期望：无确认；再开能从离开句开头继续

## TC07 鉴赏不脏槽

- 设计：界面与操作 §2 §4
- 平台：W
- 步骤：记下继续位置 → 鉴赏进已解锁节点 → 回放中 Return 与尝试 Save
- 期望：Save 不可用；回标题后主进度键（继续游戏或后日谈，视是否已解锁 after）进入鉴赏前的槽位

## TC08 无回滚 Skip Hide 确认

- 设计：需求分析 §4.2
- 平台：W A
- 步骤：滚轮、右键、找 Skip/Hide、关窗/退出
- 期望：不能上一句；无 Skip/Hide；无退出确认框

## TC09 首章假选项

- 设计：存档与播放 §3.1
- 平台：W
- 步骤：分别点两个按钮各一局（或一局点一个后读档重来）
- 期望：后续文本相同；Log 有「选择：」+ 文案

## TC10 中章纯演出

- 设计：存档与播放 §3.2
- 平台：W
- 步骤：选项出现后点按钮区域，再点空白推进
- 期望：按钮不可点、无悬停；空白可关；Log「选项（未选择）」

## TC11 尾章真选项-继续

- 设计：存档与播放 §3.3
- 平台：W
- 步骤：Staff 后选「继续」
- 期望：进入后日谈；回标题后主进度键是「后日谈」，没有「继续游戏」；没有「里·后日谈」；鉴赏紧挨主进度键下方

## TC12 尾章真选项-结束

- 设计：存档与播放 §3.3 §3.4
- 平台：W
- 步骤：选「结束」
- 期望：回标题，无确认；主进度键是「后日谈」，没有「继续游戏」；没有「里·后日谈」；点「后日谈」进后日谈第一句

## TC13 里后日谈解锁

- 设计：界面与操作 §1
- 平台：W
- 步骤：读完后日谈回标题
- 期望：主进度键仍是「后日谈」；其**正下方**出现「里·后日谈」；鉴赏在里下面。通关前标题没有「里·后日谈」

## TC14 双通关里线不循环

- 设计：存档与播放 §3.4
- 平台：W
- 步骤：after 与 inner 都读完后点「里·后日谈」
- 期望：停在里后日谈最后一句，再点不循环回首章

## TC15 里线变暗

- 设计：存档与播放 §5
- 平台：W
- 步骤：进 inner；开 Log/设置；回标题
- 期望：进入立刻暗；Log/设置保持暗；离开立刻恢复

## TC16 表里样式

- 设计：存档与播放 §4
- 平台：W
- 步骤：对比表段与尾章里段
- 期望：仅底色+字色（及共用字体）；无立绘分屏

## TC17 设置三项

- 设计：界面与操作 §6
- 平台：W A
- 步骤：打开设置；改速度档后看打字；Win 上对照 `F` 与窗口项
- 期望：只有速度/字号/窗口全屏 + 快捷键只读页（含 `F`，不要求表格对齐）；无字体项、无 Auto、无音量；A 上无窗口行；改速度后 CPS 跟着变；`F` 仍能切全屏

## TC18 Auto 自动前进

- 设计：存档与播放 §2.2
- 平台：W
- 步骤：开 Auto，不点击，等当前句打完
- 期望：按引擎 AFM 自动进入下一句

## TC19 Auto 点击跟引擎

- 设计：存档与播放 §2.2
- 平台：W
- 步骤：开 Auto 后点击（打字中途或句末均可）
- 期望：与 Ren'Py 默认 auto-forward 一致（通常退出 Auto）；不得出现「点击仍保持 Auto」的自管逻辑

## TC20 CG 鉴赏

- 设计：产品与叙事 §4
- 平台：W
- 步骤：四张 CG 出现后进鉴赏
- 期望：可打开白图+名称；未解锁为「？？？」不可开；无程序花瓣粉点

## TC21 HUD 与快捷键一致

- 设计：界面与操作 §4 §5
- 平台：W
- 步骤：对 Auto/Log/Save/Setting/Return 分别用按钮与快捷键
- 期望：行为一致；标题 Esc 不退出

## TC22 白底黑字无程序美术

- 设计：产品与叙事 §1 §5
- 平台：W A
- 步骤：浏览标题、对话、CG、名单
- 期望：白底黑字（里段深灰底白字除外）；无樱花、光尘、粉像素、转场闪白

## TC23 Android 返回键

- 设计：界面与操作 §5
- 平台：A
- 步骤：游玩中按返回；回放中按返回；设置中按返回
- 期望：同 Return 规则；回放不写槽；设置关闭自己

## TC24 静音标记

- 设计：产品与叙事 §1
- 平台：W
- 步骤：通读含 `【BGM】`/`【SE】` 的段落
- 期望：无音乐音效

## TC25 lint 门禁

- 设计：开发环境 §6；测试策略 §2
- 平台：W
- 步骤：Launcher 对本工程 Lint
- 期望：出包前无未记录错误
