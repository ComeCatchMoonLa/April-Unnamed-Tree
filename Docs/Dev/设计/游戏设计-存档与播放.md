# 游戏设计：存档与播放

- 目的：锁定单槽存档、句 ID、打字机、Auto、三类选择肢、表里样式、里线亮度。
- 读者：system、脚本、UI、测试。
- 关系：节点表见 [游戏设计-产品与叙事](游戏设计-产品与叙事.md)；字段与函数见 [接口设计-数据与存档](接口设计-数据与存档.md) 与 [接口设计-播放与UI](接口设计-播放与UI.md)。
- 版本：v1.8
- 日期：2026-09-20

## 1. 产品规则：单存档

所有写入覆盖同一逻辑槽 `slot_id = "0"`。标题主进度一键：无槽「新的游戏」；有槽且未解锁后日谈「继续游戏」；`after_unlocked` 后同一键变成「后日谈」。不能从标题新开正篇。结构按多槽设计，完整存档柜只加槽位与 UI，不改 `SaveRecord` 字段。本版本无清档按钮。

写入时机（仅 `play_mode = play`）：

1. **自动存档**：到达任一关键节点的瞬间
2. **手动存档**：Save 按钮 / `S`
3. **离开存档**：Return、退出游戏、关闭窗口，均先存当前句再执行

读取：从记录的 `line_id` 对应句子**开头**播放。不恢复打字机已显示到第几个字。

`replay` 模式禁止任何写槽。

### 1.1 记录字段（产品层）

```text
SaveRecord
  slot_id: string              # MVP 仅 "0"
  updated_at: iso8601
  chapter_id: string           # ch1 / ch2 / ch3 / after / inner
  node_id: string
  line_id: string
  style: "omote" | "ura"
  route: "main" | "after" | "inner"
  play_mode: "play"            # 存档只保存游玩
  reserved: object             # 空对象，禁止塞临时状态
```

`SaveStore.schema_version` 当前为 `1`。

解锁不放进存档槽，放全局持久数据：

```text
PersistentUnlocks
  after_unlocked: bool         # 尾章真选项已选
  inner_unlocked: bool         # 后日谈章末
  nodes: set[node_id]
  cgs: set[cg_id]
```

日后若要每槽独立解锁，把 `PersistentUnlocks` 挂到 `reserved`。本版本不预做。

### 1.2 句 ID

每一句对白 / 旁白有稳定 `line_id`：`{node_id}:{序号四位}`，例如 `ch1_start:0001`。

- 序号在节点内从 1 递增
- **插入句子时只追加新号，不重排旧号**
- 选择肢本身不是一句对白
- 中章纯演出不记录「按了哪个」

### 1.3 退出与覆盖

| 操作 | 存档 | 确认框 |
|---|---|---|
| 游玩中 Return | 写当前句到 `"0"`，回标题 | 无 |
| 游玩中退出 / 关窗 | 写当前句到 `"0"`，退出 | 无 |
| 回放中 Return | 不写槽，回鉴赏（进时分页与章签） | 无 |
| 回放停在连续已解锁末句 | 不写槽，回鉴赏（同上） | 无 |
| 回放中退出 / 关窗 | 不写槽，退出 | 无 |
| 主界面退出 | 不写槽 | 无 |
| 真选项「继续」（play，散场句后） | 写 after 首句，回标题 | 无 |
| 真选项「结束」（play，散场句后） | 写 after 首句，退出游戏 | 无 |
| 回放中真选项任一条 | 不写槽，回鉴赏 | 无 |

标题有槽且未解锁后日谈时没有「新的游戏」。`start_new_game` 仅由无槽标题（及调试探针）调用。`after_unlocked` 后标题不再调用 `continue_game`，改调 `enter_after`。

## 2. 文本播放

- 一局只显示一句。
- 点击（或触控）若当前句打字未结束：立即显示整句，**不**进入下一句。
- 当前句已完整显示后再点击：进入下一句。
- 无语音，不等语音。

### 2.1 打字速度

由设置「自动播放速度」三档决定，手动点击出字与 Auto 共用同一 CPS：

| 档 | `afm_level` | CPS | `afm_time`（秒） |
|---|---|---|---|
| 慢 | `slow` | 25 | 30 |
| 中 | `mid` | 50 | 15 |
| 快 | `fast` | 80 | 5 |

默认「中」。不单独提供打字速度项。

### 2.2 Auto

使用 **Ren'Py 默认 auto-forward**，不自写状态机。

- HUD Auto 按钮或 `A`：立刻切换 `preferences.afm_enable`（与引擎默认一致）。
- 开启后：当前句打完，引擎按 `preferences.afm_time` 等待并自动进下一句。
- 点击 / 触控：按引擎默认处理（通常会退出 Auto；打字未完则先出完当前句）。**禁止**改成「点击不退出 Auto」。
- 设置「自动播放速度」慢 / 中 / 快：同时写 `preferences.afm_time` 与 `preferences.text_cps`（上表）。
- 假选项、modal 展示肢（里·三）、Staff 真选项、Log、设置：交给引擎在这些界面上的默认暂停/恢复，不另写 pending。
- 中章留屏外观不是 modal，不暂停 Auto。
- Auto 开关属于 preference，可随设置持久化，**不写入存档槽**。

论证见 [技术选型与可行性](../调研/技术选型与可行性.md)。

## 3. 选择肢

### 3.1 首章（假选项，真按钮）

可点：

- 「那你现在，看的是花吗？」
- 「那你打算，看到什么时候？」

无论点哪个，进入同一后续文本。不写分支变量。点过后按钮消失，继续下一句。存档落在选择之后的下一句。

### 3.2 展示肢（不可点）

两类用法，不单开第四种选择肢。`run_choice_fake` / `run_choice_true` 不变。不要改 `run_choice_display` 总入口来做留屏。

#### 中章（留屏外观）

与首章选项同一套字号、居中，两行文案：

- 「等花开，去接她」
- 「尊重规则，别去打扰」

这是选项**外观**，不是可点按钮。两行用不能点的字：无底、无悬停、不吃点击。点在这两行上与点空白 / 对话框一样，只推进句子。不要因空白点击而关掉。

出现时机：`ch2_choice:0001` 之后亮出；`0002`–`0005` 播放期间两行仍在；读到「按灭屏幕」（`ch2_choice:0006`）再收。括号段中途续读，两行还在。Return / 离开必须收掉。

不进入任何分支。Log「选项（未选择）」，都不着色。另用非 modal 的 `scr_choice_hold`。首章 / 真选项仍是真按钮。

#### 里·三（关掉再读）

尾章 `ch3_ura3` 的「……」「……」走 `run_choice_display`：不可点，空白 / 对话框点击关闭，再读「我的手指停在纸上」。Log「选项（未选择）」，不标绿。本版本不把记号留到后续句上。

### 3.3 尾章（真选项）

出现在 Staff 之后。这条问的是「还看着 / 这轮放映结束」，不是「看不看后日谈」。后日谈两边都立刻解锁，从标题点入；不是「继续」拽出来的下一章。

选完不要立刻分叉。先把散场括号段给双方（「按哪个都对」落在共同最后一段），然后再分去向。

| 选项 | 解锁 | 流程 |
|---|---|---|
| 继续 | `after_unlocked = true` | 散场句后：写 after 首句，回标题。主键已是「后日谈」 |
| 结束 | `after_unlocked = true` | 散场句后：写 after 首句，无确认退出游戏 |

「里·后日谈」此时仍不出现。已通关的后日谈可从鉴赏-剧情回放。回放里点任一条：散场句后回鉴赏；不写槽、不解锁、不退出。

结束不是标题「退出游戏」的复读：标题退出是系统；这里是句子说完之后的熄灯。散场句就是间隔，不要再弹确认。

不要：继续直进 after；结束只回标题；两边都退出；选完再问一次是否退出；只有文案不同、去向相同。

两边回标题或退出后，槽都视为有存档。槽内容规定为：尾章真选项已完成，`line_id` 为后日谈第一句（`after_start` 的首句），`chapter_id = after`，`route = after`，`style = omote`。点「后日谈」才开始播放。

### 3.4 标题在真选项之后

真选项之后标题不再显示「继续游戏」。入口如下，均不循环回首章：

| 按钮 | 条件 | 行为 |
|---|---|---|
| 后日谈（主进度键） | `after_unlocked` | 槽已在 after：从该 `line_id` 句首续；否则进 `after_start`（写槽） |
| 里·后日谈 | `inner_unlocked` | 槽已在 inner：从该 `line_id` 句首续；否则进 `inner_start`（写槽） |

「已读完后日谈」的判定：`inner_unlocked == true`（后日谈章末时置位）。  
「两条都读完」：到达过 `inner_end` 章末（节点 `inner_end` 已解锁，且当前句为该章最后一句）。此时再点「里·后日谈」停在最后一句，不循环、不跳回首章。点「后日谈」仍可进 after 游玩（会覆盖槽）；不脏槽的重玩走鉴赏。

## 4. 表 / 里样式

仅用对话框背景色 + 字体区分。不做立绘、不做分屏。

| 样式 | 使用 | 对话框底 | 字色 |
|---|---|---|---|
| 表 `omote` | 正篇男主叙述、后日谈（不含 `ch3_black`） | `#FFFFFF` | `#000000` |
| 里 `ura` | 尾章里段、`ch3_black`、里后日谈 | `#2A2A2A` | `#FFFFFF` |

本版本无字体设置。表里都用随包 Maple Mono NF CN Regular，靠底色区分。不新增第三种 style。

角色名：表显示「弥生」与空名旁白；里后日谈以旁白为主，需要时显示「他」。不强制头像。

`ch3_black`（产品名仍是「表·四 黑」）按她的画面播：`style = ura`；「还在？」空 `who`；「在。」名牌「他」。节点 ID 不动。黑图以后换，名牌现在就要对。

尾章按剧本「表·N / 里·N」切换 `style`，并写入存档字段；表·四这一条例外走 `ura`。

## 5. 里线亮度

进入 `inner` 的游玩或回放：立刻全屏乘固定暗色 **黑 60% 不透明**（`#000000` alpha 0.60），无渐变。

| 情况 | 变暗 |
|---|---|
| 当前 `chapter_id == inner`（含打开 Log / 设置） | 保持 |
| 回标题、离开 inner | 立刻恢复 |

设置页若当前章是 inner，设置页也保持暗色，避免闪亮。该效果是系统色叠加，不是 CG 美术。
