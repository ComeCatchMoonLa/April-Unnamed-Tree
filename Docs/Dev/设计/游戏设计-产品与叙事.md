## 1. 产品定位

本地文字冒险。阅读为主，几乎无分支。真正影响流程的只有尾章「继续 / 结束」。

工程目标：把既有剧本做成可玩程序，并保证能扩成完整存档柜、可替换美术。

平台与明确不做见需求分析。引擎为 Ren'Py 8，论证见 [技术选型与可行性](../调研/技术选型与可行性.md)。

资源原则：

- 无正式美术、无音乐、无语音。
- 所有图片使用同一张白色占位图。
- 标题、按钮、名单一律黑字；无描边、渐变、粒子、转场、日历树等程序美术。局内中章留屏是选项外观（不能点的字），标题 / HUD 仍黑字。
- 剧本中的 `【BGM】` / `【SE】` 作为标记保留，本版本静音。

## 2. 叙事结构

全程一条时间线。后日谈、里后日谈是解锁内容，不是互斥结局枝。

| ID | 名称 | 视角 | 进入条件 |
|---|---|---|---|
| `ch1` | 首章：樱树、名字与迟到的时间 | 表（男主） | 新的游戏 |
| `ch2` | 中章：赝品、借据与不谢的花 | 表 | 读完首章自动进入 |
| `ch3` | 尾章：黑暗、手记与最后一个真正的选项 | 表 / 里交替 | 读完中章自动进入 |
| `after` | 后日谈：本日，晴，无事 | 表 | 真选项两边都解锁后，标题主进度键变成「后日谈」再点入 |
| `inner` | 里·后日谈：本日，有事 | 里（弥生） | 后日谈章末后，主进度键正下方长出「里·后日谈」再点入 |

尾章内部按剧本的「表·N / 里·N」切换样式，不拆成可单独选择的路线。

章与章之间自动衔接，不进菜单。

## 3. 关键节点

关键节点同时是：

1. 自动存档点（到达瞬间写入单槽，仅游玩模式）
2. 章节鉴赏解锁点（到达后可从鉴赏进入）

读档与鉴赏都从**该句开头**播放，不恢复打字机中途进度。

### 3.2 节点规则

- 新的游戏从 `ch1_start` 第一句开始。
- 鉴赏入口：从该节点第一句播到**本章连续已解锁的最后一句**（不含下一章、不含未解锁节点）。下一节点未解锁，或已是章末，都回鉴赏（进时分页与章签）。回放不写槽、不解锁；后续段落必须从游玩入口读过才亮。
- `ch3` 的表/里段落同属一章；从 `ch3_ura1` 进入会跳过表·一，播到本章其后连续已解锁的末句。
- `ch3_black` 产品名仍是「表·四 黑」；样式走 `ura`（她的画面），不新增 style。节点 ID 不动。
- 后日谈、里后日谈各自为一章。
- `inner_mail` 等是里后日谈章节内的节点，不是尾章 `ch3_ura*`。

## 4. CG

本版本用白色占位图，但 CG 系统按正式功能做：出现即解锁，可在鉴赏中打开。

| CG ID | 名称 | 首次出现 | 备注 |
|---|---|---|---|
| `cg_yayoi_backlight` | 逆光的弥生，花与光尘 | ch1 | 对应节点 `ch1_cg_backlight` |
| `cg_sakura_blizzard` | 樱吹雪·二人 | ch1 | 对应节点 `ch1_cg_blizzard` |
| `cg_fullbloom_backlight` | 满开·逆光 | ch2 | 尾章表·二复用同一 ID，不重复解锁 |
| `cg_black_pink` | 黑·一粒粉 | ch3 | 占位仍是白图，不做像素点特效 |

后日谈无新 CG。里后日谈无 CG。

游戏内显示 CG = 全屏白图，不叠加程序绘制的花、光、粉点。CG 鉴赏缩略图同样是白图 + 黑字标题。

未解锁 CG 在列表中显示为「？？？」且不可打开。

## 5. 占位资源

| 资源 | 文件意图 | 表现 |
|---|---|---|
| `white` | 唯一位图 | 纯白 |
| 所有 `bg_*` | 场景 | 指向 `white` |
| 所有 `cg_*` | CG | 指向 `white` |

场景切换可以换内部 tag，玩家看到的仍是白屏。不要用程序写场景名水印；场景名只存在于脚本与设计文档。CG 鉴赏列表用黑字写 CG 名称，这是 UI 文案，不是画面特效。

后续换美术：只替换对应文件或重定向 tag，不改节点表和存档字段。
