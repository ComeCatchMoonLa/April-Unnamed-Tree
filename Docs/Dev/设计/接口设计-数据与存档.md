# 接口设计：数据与存档

- 目的：给出数据记录与存档/解锁/设置/节点查询的契约。实现必须使用这些名字，参数不得超过 5 个。
- 读者：system 实现者、代码评审、AI 会话。
- 关系：字段语义见 [游戏设计-存档与播放](游戏设计-存档与播放.md)；节点 ID 见 [游戏设计-产品与叙事](游戏设计-产品与叙事.md)；播放入口见 [接口设计-播放与UI](接口设计-播放与UI.md)。
- 版本：v1.4
- 日期：2026-09-20

约定：失败返回 `None` 或 `False`，不抛给 UI。非法 ID 记日志并视为失败。复杂入参打成 record，禁止把 6 个标量并列传进一个函数。

## 1. 常量

```text
SLOT_MAIN = "0"
SCHEMA_VERSION = 1
CHAPTER_IDS = ["ch1", "ch2", "ch3", "after", "inner"]
STYLES = ["omote", "ura"]
ROUTES = ["main", "after", "inner"]
PLAY_MODES = ["play", "replay"]
```

`line_id` 格式：`{node_id}:{四位十进制}`，正则 `^[a-z0-9_]+:[0-9]{4}$`。

## 2. 记录

### 2.1 NodeDef

```text
NodeDef
  node_id: string
  chapter_id: string
  name: string
  trigger: string          # 文档用，运行时可不显示
```

### 2.2 CgDef

```text
CgDef
  cg_id: string
  name: string
  first_chapter_id: string
```

四个 CG：`cg_yayoi_backlight` `cg_sakura_blizzard` `cg_fullbloom_backlight` `cg_black_pink`。

### 2.3 SaveRecord

```text
SaveRecord
  slot_id: string
  updated_at: string       # iso8601
  chapter_id: string
  node_id: string
  line_id: string
  style: string            # omote | ura
  route: string            # main | after | inner
  play_mode: string        # 必须为 play
  reserved: dict           # 必须 {}
```

### 2.4 PersistentUnlocks

```text
PersistentUnlocks
  after_unlocked: bool
  inner_unlocked: bool
  nodes: list[string]      # 或 set，序列化稳定
  cgs: list[string]
```

### 2.5 SettingsRecord

```text
SettingsRecord
  afm_level: string        # slow | mid | fast
  font_size_level: string  # small | mid | large
  window_mode: string      # window | fullscreen；Android 忽略
```

默认：`mid`, `mid`, `window`。

读旧 persistent 时忽略已废弃的 `font_id` 键，不报错。

### 2.6 LineRef

```text
LineRef
  chapter_id: string
  node_id: string
  line_id: string
  style: string
  route: string
```

用于「当前句」快照，避免 5 个散参数。

## 3. NodeCatalog

只读。数据来自 `game/data/`。

| 函数 | 参数 | 返回 | 副作用 |
|---|---|---|---|
| `get_node` | `node_id` | `NodeDef \| None` | 无 |
| `nodes_in_chapter` | `chapter_id` | `list[NodeDef]` | 无 |
| `all_nodes` | 无 | `list[NodeDef]` | 无 |
| `chapter_of` | `node_id` | `string \| None` | 无 |
| `first_line_id` | `node_id` | `string \| None` | 无；该节点首句，序号 `0001` 除非数据另有声明 |
| `chapter_last_line_id` | `chapter_id` | `string \| None` | 无 |
| `get_cg` | `cg_id` | `CgDef \| None` | 无 |
| `all_cgs` | 无 | `list[CgDef]` | 无 |
| `route_of_chapter` | `chapter_id` | `string \| None` | `ch1-3→main`，`after→after`，`inner→inner` |

`first_line_id` 在脚本尚未标注时可按约定生成 `f"{node_id}:0001"`，但运行时必须以脚本实际首句为准。

## 4. SaveStore

唯一写槽点。本版本调用方只使用 `SLOT_MAIN`。

| 函数 | 参数 | 返回 | 副作用 |
|---|---|---|---|
| `has_slot` | `slot_id` | `bool` | 无 |
| `load_slot` | `slot_id` | `SaveRecord \| None` | 无 |
| `write_record` | `record: SaveRecord` | `bool` | 覆盖该 `record.slot_id` |
| `write_line` | `slot_id`, `line: LineRef` | `bool` | 组装 `SaveRecord`（`play_mode=play`，`reserved={}`）后写入 |
| `clear_slot` | `slot_id` | `bool` | 本版本不提供给 UI；测试或调试用 |

规则：

- `write_record` 若 `record.play_mode != "play"`：拒绝写入，返回 `False`
- `schema_version` 不匹配：读失败返回 `None`（本版本无迁移）
- `write_line` 自己填 `updated_at`
- UI 只传 `slot_id` 与当前 `LineRef`（由 PlaySession 持有），不拼 `SaveRecord`

## 5. UnlockStore

唯一写解锁点。关游戏仍在。

| 函数 | 参数 | 返回 | 副作用 |
|---|---|---|---|
| `get_all` | 无 | `PersistentUnlocks` | 无 |
| `is_node_unlocked` | `node_id` | `bool` | 无 |
| `is_cg_unlocked` | `cg_id` | `bool` | 无 |
| `is_after_unlocked` | 无 | `bool` | 无 |
| `is_inner_unlocked` | 无 | `bool` | 无 |
| `unlock_node` | `node_id` | `None` | 加入 set；重复调用幂等 |
| `unlock_cg` | `cg_id` | `None` | 幂等；`cg_fullbloom_backlight` 第二次出现不重复插入 |
| `unlock_after` | 无 | `None` | `after_unlocked = true` |
| `unlock_inner` | 无 | `None` | `inner_unlocked = true` |

`replay` 下 PlaySession **不得**调用 unlock_*。

## 6. SettingsStore

| 函数 | 参数 | 返回 | 副作用 |
|---|---|---|---|
| `load` | 无 | `SettingsRecord` | 无；缺省则返回默认值 |
| `save` | `record: SettingsRecord` | `bool` | 写入 persistent |
| `sync_afm` | 无 | `None` | 按 `afm_level` 写 `preferences.afm_time` 与 `preferences.text_cps` |
| `text_cps` | 无 | `int` | 当前档 CPS：慢 25 / 中 50 / 快 80 |
| `apply_current` | 无 | `None` | 应用字号、窗口模式、随包字体，并 `sync_afm` |
| `is_android` | 无 | `bool` | 平台探测 |

Android 上 `save` 可忽略 `window_mode`。UI 不展示该行。

## 7. 错误行为

| 情况 | 行为 |
|---|---|
| 未知 `node_id` / `cg_id` | 查询返回 `None`/`False`；unlock 忽略 |
| 槽损坏 | `load_slot` 返回 `None`，标题视为无存档 |
| 写槽时不在 play | `write_*` 返回 `False` |
| `reserved` 非空 | 本版本写入时强制改回 `{}` |
