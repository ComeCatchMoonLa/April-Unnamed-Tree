# 游戏设计：界面与操作

- 目的：锁定主界面、鉴赏、名单、HUD、快捷键、设置、Log。
- 读者：UI、播放、评审。
- 关系：节点/CG 表见 [游戏设计-产品与叙事](游戏设计-产品与叙事.md)；存档与 Auto 见 [游戏设计-存档与播放](游戏设计-存档与播放.md)；screen 名见 [接口设计-播放与UI](接口设计-播放与UI.md)。
- 版本：v1.3
- 日期：2026-09-20

视觉统一：白底黑字，无装饰动画。设计基准分辨率 1280×720，按窗口或屏幕等比缩放，不提供分辨率下拉。

## 1. 主界面（标题）

白底，黑字游戏名：`四月，未命名的树`。无背景图效果。单槽、无存档柜；标题用显隐，不拿灰掉的键占位。

竖排顺序（上到下，中间不留空行）：

1. **主进度一键**（始终占这一行，三态换字）
2. **里·后日谈**（仅 `inner_unlocked` 时出现，插在主进度键**正下方**）
3. 鉴赏、制作名单、设置、退出（始终这些；里出现时被挤到再下一行）

| 按钮 | 显示规则 | 行为 |
|---|---|---|
| 主进度：新的游戏 | 无槽 | `start_new_game` |
| 主进度：继续游戏 | 有槽且尚未 `after_unlocked` | `continue_game`（槽内 `line_id` 句首） |
| 主进度：后日谈 | `after_unlocked`（有槽；真选项后槽一直在） | `enter_after` |
| 里·后日谈 | 仅 `inner_unlocked` 时出现 | `enter_inner` |
| 鉴赏 | 始终可点 | 进入鉴赏子页（章节 / CG） |
| 制作名单 | 始终可点 | 静态名单页 |
| 设置 | 始终可点 | 打开设置 |
| 退出游戏 | 始终可点 | 主界面退出不写槽；无确认框 |

主进度看起来始终一个按钮：无槽「新的游戏」→ 有槽「继续游戏」→ 解锁后日谈后**同一键变成「后日谈」**。有槽后不能从标题新开正篇；正篇再玩走鉴赏回放。本版本无清档按钮。标题在 `after_unlocked` 之后不再出现「继续游戏」。

「里·后日谈」是长出的第二行，不要预先占坑。未解锁里时，鉴赏紧挨主进度键。

`enter_after`：槽已在 after 则从该 `line_id` 句首续；否则进 `after_start`。  
`enter_inner`：槽已在 inner 则从该 `line_id` 句首续；否则进 `inner_start`。

已通关的 after 也可从鉴赏-剧情回放（不写槽）。从标题再点「后日谈」仍是游玩，会写槽。

主界面 `Esc` 不退出游戏。退出只能点「退出游戏」。

## 2. 鉴赏

两个分页：**章节鉴赏**、**CG 鉴赏**。

章节鉴赏列出产品与叙事文中全部 29 个节点。未解锁：显示设计名称，不可进入。已解锁：进入回放模式，从该节点第一句播到本章结束。已通关的后日谈节点也在此回放，与标题「后日谈」（游玩、会写槽）不是同一入口。

CG 鉴赏列出四个 CG。打开后全屏白图 + 名称，点击返回列表。未解锁显示「？？？」且不可打开。

回放模式规则见存档与播放文：不写槽。

## 3. 制作名单

静态白底黑字，不滚动、不配乐。内容固定：

```text
脚本：弥生
演出：四月
校对：他的耳朵
原谅：彼此

引擎：Ren'Py
```

点击任意处或快捷键返回主界面。此页是主界面「制作名单」，与尾章 `ch3_staff` 的 Staff 演出不是同一入口；尾章 Staff 之后接真选项。

## 4. 游戏内 HUD

仅游玩 / 回放显示。底部或边角固定五键，黑字，无装饰。

| 按钮 | 游玩模式 `play` | 回放模式 `replay` |
|---|---|---|
| Return | 先自动存档，再回标题 | 不存档，直接回标题 |
| Auto | 切换引擎默认 Auto（`preferences.afm_enable`） | 同左 |
| Setting | 打开设置 | 同左 |
| Log | 打开对话回顾 | 同左 |
| Save | 手动写入单槽 `"0"` | 不可交互 |

回放模式不写自动存档，避免覆盖「继续游戏」。

## 5. 快捷键

只在 Windows 生效。Android 只用按钮；系统返回键 = Return（遵守当前模式的存档规则）。

| 功能 | 快捷键 | 作用域 |
|---|---|---|
| Auto | `A` | 游戏场景 |
| Log | `L` | 游戏场景 |
| Save | `S` | 游戏场景（回放中无效） |
| Setting | `F1` | 游戏场景、主界面、鉴赏、名单 |
| Return | `Esc` | 游戏场景（回标题，先按 HUD 存档规则） |

设置页打开时：`F1` 或关闭按钮关闭设置，不触发 Return。

快捷键说明放在设置的「快捷键」分页，文案与上表一致，并注明安卓无快捷键。本版本不可改键。

HUD 五键与快捷键行为必须一致。

## 6. 设置

入口：主界面「设置」、游戏内 Setting、`F1`。

两个分页：**选项**、**快捷键**。

### 6.1 选项（仅这四项）

| 项 | 范围 | 说明 |
|---|---|---|
| 自动播放速度 | 慢 / 中 / 快 | 映射到引擎 `preferences.afm_time`（句间等待）。默认「中」。不改打字 CPS |
| 字体大小 | 小 / 中 / 大 | 对白、Log、按钮文本跟从。默认「中」 |
| 字体选择 | 内置列表 | 至少无衬线 / 衬线两套。**本版本一个下拉，表里共用**，靠底色区分 |
| 窗口 / 全屏 | 窗口、全屏 | 仅 Windows。Android **隐藏**该行 |

默认字体文件（实现阶段可换同许可开源文件，但必须随包）：

- 无衬线：Noto Sans SC
- 衬线：Noto Serif SC

不放进设置：Auto、Log、Save、Return、鉴赏、继续 / 新游戏、音量、语音、Skip、回滚、语言。

### 6.2 快捷键分页

只读，内容同第 5 节。

## 7. 对话回顾 Log

- 记录已显示过的对白与旁白（角色名 + 文本）。
- 只读，不可点击某行跳转。
- 首章选择：系统行「选择：」+ 玩家点到的文案。
- 中章纯演出：系统行「选项（未选择）」。
- 尾章真选项：系统行「选择：继续」或「选择：结束」。
- 关闭 Log 回到当前句。Auto 开关是引擎 preference，不在 Log 里改。
- 打开 Log / 设置期间，句间自动前进按引擎默认暂停（模态 screen）。
