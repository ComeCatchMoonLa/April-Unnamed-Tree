# 架构设计

- 目的：锁定目录、分层、依赖方向、引擎关闭项与存档落点。实现必须按此拆文件。
- 读者：实现、评审、AI 会话。
- 关系：玩法来自游戏设计三篇。函数契约见两篇接口设计。文件落点细则见 [接口实现约定](../实现/接口实现约定.md)。
- 版本：v1.5
- 日期：2026-09-20

## 1. 目录

根目录即 `Sakura/`。文档在 `Docs/`（不是 `docs/`）。

实现阶段创建（本轮不建工程）：

```text
Sakura/
  Docs/                    # 开发与资源文档
  game/
    script/                # 按章拆 .rpy 脚本
    system/                # 存档、解锁、播放、节点查询
    ui/                    # 菜单、HUD、设置、Log、鉴赏、选择肢
    data/                  # 节点、CG、快捷键文案、Staff 文案
    images/                # white 及引用
    fonts/                 # 随包中文字体
  .vscode/                 # 实现阶段按调研模板拷贝
```

单目录文件不超过 15 个。超出按「脚本 / 系统 / UI / 数据」再拆子目录，而不是堆进 `game/` 根。

`game/` 根只放 Ren'Py 必需入口（如 `options.rpy`、`gui.rpy` 的瘦身版或转调文件），禁止把玩法写进默认大文件后不管。

## 2. 分层

```text
data（只读表）
  → system（存档 / 解锁 / 播放 / 节点目录）
    → script（章脚本只调用 system，不直接写 persistent）
    → ui（screen 只调 system，只传 slot_id 等标识）
```

依赖方向禁止反向：`data` 不知 UI；`system` 不知具体 button 文案布局（选择肢文案可放 data 或由脚本传入 record）。

```text
data_nodes_cgs
    → system_play
    → system_unlock
system_save  → system_play
system_unlock → system_play
system_play → script_chapters
system_play → ui_screens
```

## 3. 运行时模式

| 模式 | 来源 | 写槽 | 写解锁 |
|---|---|---|---|
| `play` | 新的游戏、继续游戏、后日谈、里·后日谈 | 是 | 是（到达节点/CG/真选项/章末） |
| `replay` | 章节鉴赏 | 否 | 否（节点应已解锁才进得来） |

CG 鉴赏打开全屏图不是 `replay` 文本播放，不进入播放会话，不写槽。

## 4. 引擎默认功能

在 `options` / 等价配置中关闭，且 UI 不得再提供入口：

| 项 | 要求 |
|---|---|
| rollback | 关。滚轮、右键不得上一句 |
| Skip | 关 |
| Hide | 关 |
| 退出确认 | 关 |
| 默认存档柜 | 不显示、不绑定快捷键 |
| 默认 auto-forward | **开**。HUD / `A` 只切换引擎 AFM，不自写 Auto 状态机 |

Android：恒定全屏；系统返回键绑定与 HUD Return 相同的 system 入口。

Windows：允许窗口/全屏。设置窗口项、快捷键 `F` 与 `SettingsStore` 共用 `preferences.fullscreen`；不要关掉引擎 `toggle_fullscreen`。

## 5. 存档架构

- `SaveStore` 是写槽**唯一**模块。内部可用 Ren'Py slot 持久化 `SaveRecord`。
- `UnlockStore` 是写解锁**唯一**模块。内部用 `persistent`。
- UI 与脚本不得调用 `renpy.save` / `renpy.load` / 直接改 `persistent.nodes`。
- 本版本只暴露 `slot_id = "0"`。`SaveStore` 的 map 结构保留多槽。

读档恢复：只恢复 `SaveRecord` 中的章、节点、句、样式、路线，然后从该 `line_id` 开头播放。不恢复 CPS 进度。Auto 开关是引擎 preference，不进存档槽。

设置项（速度档、字号、窗口模式）走 `SettingsStore`，也放 `persistent`，与解锁分开字段，避免耦合。无 `font_id`。

## 6. 脚本与数据

- 节点表、CG 表、解锁条件、快捷键说明文案放 `game/data/`。
- 章脚本放 `game/script/`，建议：`ch1.rpy` `ch2.rpy` `ch3.rpy` `after.rpy` `inner.rpy`，外加 `lines` 或按节点拆文件，保持单文件 ≤500 行、单目录 ≤15。
- 每句对白必须带稳定 `line_id`。允许用 helper（参数 ≤5）包装 `narrator` / character。
- 到达节点时调用 `PlaySession.on_node_reached`，由它决定是否存档、是否解锁。

## 7. UI 结构

screen 清单见播放与 UI 接口。原则：

- 一个 screen 一个文件，或按「标题 / HUD / 设置 / 鉴赏」分组，仍遵守 15 文件上限。
- HUD 是 overlay，不替代对话 window。
- 选择肢三类入口三个独立 screen，禁止一个 screen 用大量 `if` 模拟三种交互。
- 中章留屏另用 `scr_choice_hold`（可与选择肢同文件），禁止把 `scr_choice_display` 改成留屏。

## 8. 字体与图像

- 字体只从 `game/fonts/` 引用。本版本仅 Maple Mono NF CN Regular 一套。
- 图像：`white` 为唯一位图；`bg_*` / `cg_*` 重定向到它。
- 里线变暗：独立 overlay 层，由 `PlaySession` 根据 `chapter_id` 开关，不写在 CG 上。

## 9. 启动路径

1. 引擎启动 → 应用 `options` 关闭项 → 读 `SettingsStore` / `UnlockStore`
2. 进入标题 screen
3. 用户操作 → `PlaySession` 对应入口 → 跳转章 label
4. 章脚本按 `line_id` 播放；节点回调 system
5. 回标题或退出时按模式写槽
