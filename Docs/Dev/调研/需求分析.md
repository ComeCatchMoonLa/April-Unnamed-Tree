# 需求分析

- 目的：锁定本版本要做什么、不做什么，作为设计与验收的上游。
- 读者：设计、实现、评审、AI 会话。
- 关系：下游是 [技术选型与可行性](技术选型与可行性.md) 与游戏设计三篇。不讨论引擎实现。
- 版本：v1.5
- 日期：2026-09-20
- 剧本源：[Docs/Res/剧本.txt](../../Res/剧本.txt)

## 1. 产品定义

这是一款**本地运行**的文字冒险（ADV / Galgame）。玩法以阅读为主，几乎无剧情分支。选项多数是假的；真正影响流程的只有尾章「继续 / 结束」。

工程目标不是做通用引擎，而是把既有剧本变成可玩程序，并保证后续能扩成完整存档柜、可替换美术。

游戏显示名：`四月，未命名的树`。

## 2. 用户与场景

| 角色 | 场景 |
|---|---|
| 玩家（Windows） | 下载可执行文件，窗口或全屏阅读 |
| 玩家（Android） | 安装 APK/AAB，恒定全屏阅读 |
| 开发者 / AI | 按 `Docs/Dev` 把剧本做成可玩程序 |

不做运营后台、不做账号、不做联机。

## 3. 平台需求

| 平台 | 形态 | 说明 |
|---|---|---|
| Windows 10+ | 本地可执行程序 | 支持窗口 / 全屏 |
| Android 5.0+ | 本地安装包（APK/AAB） | 恒定全屏；忽略窗口选项 |

明确不做：网页端、iOS、Linux、macOS 发行。

## 4. 功能需求

### 4.1 必须有

1. 按剧本线性播放五段：`ch1` → `ch2` → `ch3`，以及解锁后的 `after`、`inner`。
2. 主界面：主进度一键（新的游戏 / 继续游戏 / 后日谈 三态）、可选的里·后日谈（插在主进度键正下方）、鉴赏、制作名单、设置、退出。细则见界面与操作 §1。
3. 单槽存档，可扩展为多槽而不改记录字段。
4. 关键节点自动存档 + 手动存档 + 离开时存档（仅游玩模式）。
5. 章节鉴赏与 CG 鉴赏；回放不覆盖继续存档。
6. 表 / 里仅用对话框底色区分；里后日谈全屏乘暗。
7. 设置仅三项 + 只读快捷键页。
8. HUD 五键：Return、Auto、Setting、Log、Save。
9. 三类选择肢：首章可点但殊途同归；中章不可点；尾章真选项。
10. 白占位图走完整 CG/场景管线，便于以后换图。

细节以游戏设计三篇为准，本文件只锁范围。

### 4.2 明确不做

| 项 | 说明 |
|---|---|
| 回滚 Rollback | 滚轮 / 右键上一句、历史跳转回放均不做 |
| Skip / 快进 / Hide | 不做 |
| 退出确认 | 关窗、返回、退出均不弹确认框 |
| 多周目强制二周目解锁 | 不采用原剧本「通关两次才出后日谈」 |
| 网页版 | 不做 |
| 程序美术效果 | 不做转场、闪白、花瓣、打字以外的动效 |
| 语音 | 不做；因此回滚没有回听价值 |
| 音乐播放 | `【BGM】` / `【SE】` 只留标记，本版本静音 |
| 正式美术 | 全用同一张白色占位图 |
| 多语言 | 不做 |
| 改键 | 本版本快捷键固定 |
| 字体选择 | 不做下拉；随包一套 Maple Mono NF CN Regular |

## 5. 资源需求

- 无正式美术、无音乐、无语音。
- 所有图片资源使用同一张白色占位图。
- 标题、按钮、名单一律黑字，不做描边、渐变、粒子、转场动画、日历树等程序美术。
- 中文字体随包分发，不读用户系统字体。

## 6. 非功能需求

| 项 | 要求 |
|---|---|
| 离线 | Win / Android 均可脱离编辑器运行 |
| 续玩 | 杀进程后再开，从记录句的**开头**继续 |
| 可扩展存档 | `slot_id = "0"` 为唯一暴露槽；字段按多槽设计 |
| 可换美术 | 换文件或重定向 tag，不改节点表和存档字段 |
| 可读性 | 1280×720 为设计基准，双端字体大小可读 |
| 工程约束 | 单文件 ≤500 行，单函数 ≤300 行，参数 ≤5 个，单目录 ≤15 个文件 |

## 7. 成功标准

以 [验收清单](../测试/验收清单.md) 全部通过为本版本完成定义。摘要：

- 双端可运行，无网页构建物
- 单槽、有槽不能从标题新开、鉴赏不脏槽
- 无回滚 / Skip / Hide / 退出确认
- 三类选项行为正确；真选项解锁后日谈
- 里线变暗；设置只有速度、字号、窗口/全屏三项
- Auto：引擎默认 auto-forward（点开关、点击退出等均跟引擎）

## 8. 非目标（本版本之后才考虑）

- 十槽存档柜 UI
- 每槽独立解锁
- 正式立绘、CG、BGM、SE、语音
- 字体设置 / 表里两套独立字体下拉（本版本无字体项，一套随包）
- iOS / Web
