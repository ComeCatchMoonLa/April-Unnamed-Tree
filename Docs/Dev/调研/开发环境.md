# 开发环境

- 目的：规定 Cursor Profile「Py Dev」在本仓库如何用、插件增删、lint 是否引入。
- 读者：在本机打开本仓库的人、实现阶段配置工作区的人。
- 关系：可行性总论见 [技术选型与可行性](技术选型与可行性.md)；何时跑 lint 见 [测试策略](../测试/测试策略.md)。Git 不负责插件。
- 版本：v1.2
- 日期：2026-09-20

本轮**只给模板，不落盘** `.vscode/`，也不改用户级 Cursor Profile。实现阶段按本文拷贝。

## 1. 原则

本仓库使用 Cursor Profile **Py Dev**。

不在用户级卸载 Python 工具：其它 Python 项目仍需要它们。用**本仓库工作区设置覆盖**做隔离。

本机已观察到的现状（2026-09-15）：

| 项 | 现状 |
|---|---|
| Profile | `Py Dev`（`User/profiles/-81f627`） |
| 用户级已装 | `ms-python.python`、`anysphere.cursorpyright`、`ms-python.debugpy`、`charliermarsh.ruff` |
| 用户 `settings.json` | `[python]` 默认格式化为 Ruff |
| Py Dev | 全局 `editor.formatOnSave: true` |
| Ren'Py 语言扩展 | 尚未安装 |

打开本仓库时请切到 **Py Dev**（不要沿用「Unity Game Dev」等其它 Profile）。

## 2. 必须新增

| ID | 名称 | 作用 |
|---|---|---|
| `renpy.language-renpy` | Ren'Py Language (8.3+) | `.rpy` 语法、诊断、语言 ID `renpy` |

不要安装旧社区扩展 `LuqueDaniel.languague-renpy`（ID 含历史拼写错误）。双扩展会抢 `.rpy` 语言模式。

工作区推荐文件模板（实现阶段写入 `.vscode/extensions.json`）：

```json
{
  "recommendations": ["renpy.language-renpy"],
  "unwantedRecommendations": ["LuqueDaniel.languague-renpy"]
}
```

可选：在 Py Dev Profile 里启用 `renpy.language-renpy`。未启用时，接受工作区推荐即可。

## 3. 必须停用或覆盖（不是卸载）

不要从 Py Dev / 用户级卸掉下列扩展。只在本工作区关掉它们对 `.rpy` 的作用。

| 扩展 | 用户级 | 本工作区 |
|---|---|---|
| `charliermarsh.ruff` | 保留 | 禁止格式化或检查 `.rpy`。Format on Save + Ruff 会拆 `label` / `screen` / `$` 与中文对白 |
| `ms-python.python` | 保留 | 禁止把 `.rpy` 当 Python |
| `anysphere.cursorpyright` | 保留 | 不要分析剧本；满屏假报错 |
| `ms-python.debugpy` | 保留 | 不要作为本项目启动器。运行走 Ren'Py Launcher |

也不要把系统 Python 或 venv 当成游戏运行时。

## 4. Py Dev 中保留的扩展

对 Ren'Py 有用，保持启用：

- indent-rainbow
- trailing-spaces
- Error Lens（须在正确的 `renpy` 语言模式下，否则放大 Pyright 假报错）
- cSpell（加入专有词）
- Project Manager

cSpell 建议词：`弥生` `omote` `ura` `RenPy` `line_id` `slot_id`。

## 5. 工作区 settings 模板

实现阶段写入 `.vscode/settings.json`。用于压过 Py Dev 的全局 Format on Save 与 Ruff。

```json
{
  "files.associations": {
    "*.rpy": "renpy",
    "*.rpym": "renpy"
  },
  "files.exclude": {
    "**/*.rpyc": true,
    "**/*.rpymc": true,
    "**/cache": true,
    "**/saves": true
  },
  "search.exclude": {
    "**/*.rpyc": true,
    "**/cache": true,
    "**/saves": true,
    "**/dist": true
  },
  "[renpy]": {
    "editor.formatOnSave": false,
    "editor.defaultFormatter": null
  },
  "ruff.enable": false,
  "ruff.exclude": ["**/*.rpy", "**/*.rpym"],
  "python.analysis.exclude": ["**/*.rpy", "**/*.rpym", "**/game/saves", "**/cache"],
  "python.analysis.ignore": ["**/*.rpy", "**/*.rpym"]
}
```

说明：

- `ruff.enable: false` 是本仓库总开关。若日后出现**不含** `import renpy` 的纯 `.py` 数据模块，可改为仅 exclude 剧本，并对该 `.py` 单独开 Ruff。本版本默认逻辑写在 `.rpy` 的 `init python` 中，因此整库关 Ruff。
- 不要为本项目添加 debugpy 的 `launch.json`。
- 不要设置 `python.languageServer` 去分析 `.rpy`。

编辑器红线只采信：Ren'Py 官方扩展诊断，以及 `renpy lint`。不采信 Pyright 对剧本的诊断。

## 6. 流程工具取舍

| 工具 | 本阶段 | 理由 |
|---|---|---|
| `renpy lint` | **要** | 引擎自带，唯一官方、懂 `.rpy` 的检查器 |
| Ruff / Black / isort / Pylint / Flake8 | **不要** 跑 `.rpy` | 语法不是 CPython |
| pre-commit | **不要** | 本阶段无协作挂钩收益 |
| GitHub Actions CI | **不要** | 无构建矩阵价值 |
| debugpy `launch.json` | **不要** | 运行时是 Ren'Py |
| pytest | **不要默认** | 见 [测试策略](../测试/测试策略.md) |

### 6.1 `renpy lint` 规格

- 何时：本地打开工程能跑通后；每次准备出 Win/Android 包之前必须再跑。
- 失败：阻断出包。允许带着已知的、已记录的引擎误报继续开发，但出包前必须清零或在测试记录里写明误报。
- 不替代 [验收清单](../测试/验收清单.md)。lint 过仍要手工点存档、三类选项，并确认 Auto 仍是引擎默认。

命令以 SDK 文档为准，在 Ren'Py Launcher 对该工程执行 Lint。不要用系统 `pip` 装第三方「renpy linter」替代。

## 7. 开发用开关（`game/system/debug.rpy`）

`splashscreen` 调用 `debug_apply_boot`。只写槽和解锁，不自动开播，进标题后再点。不要做句级定位，也不要做调试界面。

| 常量 | 取值 | 作用 |
|---|---|---|
| `DEBUG_START` | `None` | 不动槽、不动解锁（测杀进程续玩） |
| `DEBUG_START` | `"new"` | 清槽、清解锁（旧 `DEBUG_RESET_ON_BOOT True`） |
| `DEBUG_START` | `(chapter_id, node_id)` | 槽写该节点 `:0001`；点亮 `NODE_DEFS` 到该节点（含）的节点与对应 CG；章为 `after` 则 `after_unlocked`；章为 `inner` 则 `after`+`inner`。停在 after 不置 inner |
| `DEBUG_UNLOCK_GALLERY` | `True` / `False` | 全开节点与 CG，不改槽。与 `DEBUG_START` 独立 |

`chapter_id` / `node_id` 与节点表一致，例如 `("after", "after_read")`、`("inner", "inner_start")`。章与节对不上则记日志、不动档。已去掉 `DEBUG_RESET_ON_BOOT`。

仓库默认 `DEBUG_START = None`。不要提交停在某一节的元组。出包前必须是 `None` 或 `"new"`。

## 8. 实现阶段检查单

拷贝 `.vscode` 模板并安装官方扩展后，确认：

1. 打开任意 `.rpy`，右下角语言模式是 `Ren'Py` / `renpy`，不是 `Python`
2. 保存 `.rpy` 不会被 Ruff 改写
3. Problems 面板没有把 `label` 当 Python 语法错误
4. 能从 Ren'Py Launcher 启动本工程（工程尚未创建前可跳过）
