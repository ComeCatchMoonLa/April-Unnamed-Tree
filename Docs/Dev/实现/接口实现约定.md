# 接口实现约定

- 目的：把接口契约落到建议路径，并定义「做完」的标准。
- 读者：实现者、AI 会话。
- 关系：契约原文是两篇接口设计；风格见 [编码规范](编码规范.md)。
- 版本：v1.3
- 日期：2026-09-20

本轮不创建这些文件。实现阶段按表创建，单目录保持 ≤15 个文件。

## 2. 唯一写入点

| 动作 | 只允许 |
|---|---|
| 写槽 | `SaveStore.write_record` / `write_line` |
| 读槽 | `SaveStore.load_slot` / `has_slot` |
| 写解锁 | `UnlockStore.unlock_*` |
| 改设置 | `SettingsStore.save` |
| 切换 Auto | `toggle_afm`（即 `preferences.afm_enable`） |

HUD、快捷键、Android 返回键必须调用同一 `commit_leave` / `write_line` / `toggle_afm`。

## 3. 平台约束

- Android：恒定全屏；隐藏窗口/全屏设置行；返回键 = Return。
- Windows：设置可切窗口/全屏。
- 字体只引用 `game/fonts/`。
- 里线暗层由 `sync_inner_dim` 统一开关，不要在每个 inner label 手写一遍且漏标题恢复。

## 4. Auto 实现约束

- **打开**引擎默认 auto-forward，不要关。
- HUD Auto 与 `A` 只切换 `preferences.afm_enable`。
- 禁止自写句间等待公式、pending/active、点击不退出。
- `SettingsStore.sync_afm` 同步三档 `afm_time`。

## 5. 完成定义

一个子系统「实现完成」= 对应接口测得通，而不是「能点进游戏」。

对照：

| 子系统 | 完成 |
|---|---|
| SaveStore | 写读槽 `"0"`；replay 调用被 PlaySession 挡住；损坏槽当无存档 |
| UnlockStore | 真选项后主进度键变为后日谈；after 章末 inner **出现在其正下方**；关游戏仍在 |
| PlaySession | 无槽新的游戏；未解锁 after 时继续；`enter_after` / `enter_inner` 按槽续玩；replay 不写槽 |
| Auto | 引擎 AFM 可开可关；点击行为与默认一致；无自管状态机 |
| UI | 标题主进度三态 + 里插位、五键、四设置项、无退出确认 |
| 脚本 | 29 节点可到达；四 CG 解锁；三类选择肢 |

出包前：`renpy lint` 通过 + [验收清单](../测试/验收清单.md) 勾完。
